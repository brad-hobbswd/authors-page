# Brad Hobbs | Official Author Website

The official author website of **Brad Hobbs**, Christian author and biblical teacher. The site brings together books, biblical studies, devotional writing, Christian living resources, fiction, memoir, family stories, and ministry projects centered on Scripture and Jesus Christ.

## Visit the Website

**Live website:** https://brad-hobbswd.github.io/authors-page/

## What You Will Find

### Featured Publications

The home page highlights selected recent publications, including:

- **I Refuse to Stay Bound:** Biblical teaching on offense, bitterness, forgiveness, and spiritual freedom.
- **Beyond the Veil:** A study of God's authority, obedience, the heart, and the responsibility of spiritual leadership.
- **From the Bottom to Grace:** A personal family story of struggle, hope, and grace.

### Biblical Studies and Book Series

The site also features selected biblical and historical studies, including *Sodom and Gomorrah* and *The Offering God Can Accept*, as well as the Question Series:

- *Who Made You Judge?*
- *Who Gave You Authority?*
- *Who Do You Call, Savior?*

### Main Pages

- **Home:** Featured publications, selected studies, and updates.
- **About:** Background on the author and the purpose behind the writing.
- **Library:** A broader collection of books, studies, and related projects.
- **Contact:** Ways to get in touch.

## Website Technology

This is a static website built with:

- HTML5 for page structure
- CSS3 for layout, styling, and responsive presentation
- JavaScript for interactive features
- GitHub Pages for hosting


Additional image assets are stored in the repository root and the `images/` directory.

## Local Preview

To preview the site locally, download or clone the repository and open `index.html` in a web browser. Some links point to other independently hosted book and study websites, so an internet connection is needed to open those destinations.
